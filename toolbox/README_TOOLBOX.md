# ArcGIS Pro MCP Live Sync Toolbox (`MCP_Sync.pyt`)

The **MCP Live Sync Toolbox** enables instant, zero-restart synchronization between your AI assistant (via the ArcGIS Pro MCP Server) and an active, open ArcGIS Pro desktop session.

---

## The Challenge: ArcGIS Pro File Locks

When ArcGIS Pro is running with a project open, it places an exclusive OS-level file lock on `<ProjectName>.aprx`. When external tools (like the MCP Server running in Python) attempt to modify `.aprx` directly, ArcGIS Pro prevents direct overwriting to preserve project integrity.

The MCP Server automatically handles this by:
1. Exporting updated projects to `<ProjectName>_updated.aprx`.
2. Emitting `active_basemap_state.json` containing basemap configuration, coordinate systems, and parameters.
3. Exporting `Active_Basemap.lyrx` or styled layer files.

The **`MCP_Sync.pyt`** toolbox completes the cycle from **inside** ArcGIS Pro, using `arcpy.mp.ArcGISProject("CURRENT")` to update the active map display **in real-time without restarting ArcGIS Pro**.

---

## Toolbox Contents

`MCP_Sync.pyt` includes three tools:

### 1. `Sync Basemap and Coordinate System` (`SyncBasemapAndCRS`)
- **Reads**: `active_basemap_state.json` from the project directory.
- **Updates**:
  - Replaces active basemap layers with gallery basemaps (e.g. *Topographic*, *Imagery*, *Streets*, *Dark Gray Canvas*) or custom XYZ tile services (e.g. *Google Satellite*, *OpenStreetMap*, *CartoDB*).
  - Updates the active map's Coordinate System / Spatial Reference (EPSG / WKID).
- **Parameters**:
  - `State JSON File` (Optional): Path to `active_basemap_state.json`. Defaults to auto-discovering in project home folder.
  - `Target Map Name` (Optional): Name of the map to update. Defaults to the active map view.
  - `Project File` (Optional): Used when running in batch/standalone mode outside the Pro GUI.

### 2. `Apply Layer File (.lyrx) to Active Map` (`ApplyLyrxToActiveMap`)
- **Reads**: `Active_Basemap.lyrx` or any `.lyrx` generated by the MCP Cartography & Symbology tools.
- **Updates**: Injects the layer into the map view immediately.
- **Parameters**:
  - `Layer File (.lyrx)` (Optional): Defaults to `Active_Basemap.lyrx`.
  - `Target Map Name` (Optional).
  - `Replace Existing Basemap` (Boolean): Removes older basemap layers if true.

### 3. `Sync All MCP Changes` (`SyncAllFromMCP`)
- **One-click execution**: Automatically runs full state synchronization for basemaps, coordinate systems, and active layers in one operation.
- **Parameters**:
  - `Project File` (Optional): Project path (.aprx) if executing outside ArcGIS Pro GUI.
  - `Target Map Name` (Optional): Name of the map to update. Defaults to the active map view.
  - `State JSON File` (Optional): Path to `active_basemap_state.json`. Defaults to auto-discovery.
  - `Layer File (.lyrx)` (Optional): Path to `.lyrx` file. Defaults to auto-discovery.

## How to Add the Toolbox to ArcGIS Pro

1. Open **ArcGIS Pro**.
2. Open your project (`.aprx`).
3. In the **Catalog Pane** (View -> Catalog Pane):
   - Right-click **Toolboxes** -> **Add Toolbox**.
   - Navigate to `c:\Pavlos_project's\ArcGIS_Pro_MCP\toolbox\MCP_Sync.pyt` and click **OK**.
4. Double-click **Sync Basemap and Coordinate System** or **Sync All MCP Changes** and click **Run**.

---

## Adding to the Quick Access Toolbar

To synchronize with a single click:
1. In the Catalog pane, navigate to `MCP_Sync.pyt` -> right-click `Sync All MCP Changes`.
2. Select **Add to Quick Access Toolbar**.
3. Now, whenever the AI assistant applies a new basemap or coordinate system, simply click the Quick Access button in ArcGIS Pro for instant refresh!

## Standalone / Scripted Execution

The toolbox can also be invoked programmatically via ArcPy:

```python
import arcpy

# Import the custom Python toolbox
arcpy.ImportToolbox(r"c:\Pavlos_project's\ArcGIS_Pro_MCP\toolbox\MCP_Sync.pyt")

# Execute sync tool on a project
arcpy.mcpsync.SyncBasemapAndCRS(
    state_file=r"C:\Projects\MyGISProject\active_basemap_state.json",
    target_map_name="Map",
    project_path=r"C:\Projects\MyGISProject\MyGISProject.aprx",
)
```
